# K & R Capital Partners app

Installable web app for kandrcapitalpartners.com.

Open `index.html` after it is hosted on HTTPS (your domain, Netlify, or Vercel). Home-screen install only works from a secure origin, not from a file on the phone.

What it includes
- Home, loan programs, payment sketch, consultation request
- English / Spanish toggle
- Email handoff to info@kandrcapitalpartners.com
- Links back to the live program pages
- Broker disclaimer: not a lender, figures are starting ranges

Install
- Android Chrome: menu or the Install banner, then Add to Home screen
- iPhone Safari: Share, then Add to Home Screen
